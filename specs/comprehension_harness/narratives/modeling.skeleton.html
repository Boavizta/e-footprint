Modeling

What the library does when a modeler builds a system, edits it and reads its footprint, told by the code that does it. Each narrative below is what the library does for one action, walked in the order one test crosses it: the cause the modeler sets off, then every step the library takes. A step is a sentence written at its own line, with the values the test saw there. What the engine does underneath is told by the mechanism narratives, a page each.

A dotted link opens VS Code at the line. Right-click it for the diff against main or, on a test, to debug that case.
