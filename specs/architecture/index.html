A typical modeling object

Most domain classes assign their inputs in __init__, then declare each derived value as a decorated getter. This abridged example is the real shape of UsagePattern.

Inputs are stored; the formula reads like ordinary Python
class UsagePattern(ModelingObject):
    def __init__(self, name, country, hourly_usage_journey_starts, ...):
        super().__init__(name)
        self.country = country
        self.hourly_usage_journey_starts = hourly_usage_journey_starts

    @computed_attribute
    def utc_hourly_usage_journey_starts(self):
        converted = self.hourly_usage_journey_starts.convert_to_utc(
            local_timezone=self.country.timezone
        )
        return converted.set_label("Hourly journey starts (UTC)")
Value dependencies
The result uses hourly_usage_journey_starts and the linked country's timezone.
Relationship dependency
The result also depends on which Country the country link points to.

The reactive framework observes those ordinary reads while the getter runs. Continue with the complete recomputation walkthrough for the exact runtime state, code paths, invalidation, and persistence behavior.
