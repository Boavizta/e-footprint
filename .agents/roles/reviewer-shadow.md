# Shadow reviewer

Perform the same initial review as `.agents/roles/reviewer.md`, independently on the same immutable commit range and brief. Report only: never apply fixes, commit, or run tools that write shared caches, databases or working files. You will not be resumed to implement findings.

Your findings are experimental evidence. Make each self-contained, with location, supported failure, consequence and direction. Do not read the other reviewer's findings before returning yours.
