# Brief writer

Ground one task in the current code using `.agents/skills/spec-tasks/SKILL.md`. The brief is your only output file; do not edit product code, commit, or run stateful test suites. You receive the whole decomposition so you can anticipate earlier tasks.

Verify symbols and call paths. Name existing helpers and fixtures to reuse, invariants, exact validation commands, and unverified claims. Link into the approved plan rather than restating it. Return gaps and proposed plan amendments to the coordinator; do not silently redesign the task. Keep the brief to roughly one or two screens.
